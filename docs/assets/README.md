# Logo assets

These files were generated by a one-off Node script, which is not kept in the repo: the mark is hand-drawn round-capped strokes on a 100 unit box, and the wordmark is "lookover" in JetBrains Mono ExtraBold at 96 units on an 85 unit baseline, converted to outline paths with opentype.js so no file depends on a font. The brand colour is orchid #B86BF0, the ink is #1F2937 on light and #E6EDF3 on dark, and logo-card.svg puts the dark lockup on a #10151C card with a #222B36 border, matching hive and jig. The small mark is a separate, heavier drawing for 16px, and it must stay identical to `markShapes` in src/page.ts, which draws the page's header mark and favicon; a test in src/server.test.ts pins that. social-preview.png is the dark lockup plus the tagline at 1280x640, screenshotted with headless Chrome. To change the set, redraw from these numbers and regenerate every file together.
